# EPSC2026-Wills-Masters-Thesis

This is the GitHub repo for my EPSC poster, based on my master's thesis at FU Berlin in the Planetary Science and Space Exploration Program.

## EPSC 2026 abstract template note

I could not find an official downloadable LaTeX template for EPSC 2026 abstract submission.
The conference guidance appears to use an online submission workflow instead:

- https://www.epsc2026.eu/
- https://www.epsc2026.eu/programme/how-to-submit.html

To make drafting easier, this repo now includes a small local LaTeX starter project in [`epsc2026-abstract/`](./epsc2026-abstract/) with:

- `main.tex`
- `references.bib`
- `figures/source/`
- `figures/exported/`
